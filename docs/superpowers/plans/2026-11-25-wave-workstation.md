# 二维波动工作站首版实施计划

对应[已确认的设计](../specs/2026-11-25-2d-wave-workstation-design.md)。本次交付第一阶段，直接用浏览器打开，也可通过项目的本地服务器使用。

- [x] **配置与传递。** 在 `advanced.html` 从内存带入实验。在 `wave-scene.js` 完成旧配置检查、一维材料向二维展开、独立实验文件与默认 4f。检验旧格式、重开笔迹、非法材料份额及不能传播的器件。
- [x] **逐面计算。** 在 `wave-solver.js` 提供 `run(scene, options)`，以 mm 和 nm 为输入，输出每条谱线的二维 Stokes 图、指定分量的相位、物理尺寸、能量账与诊断。检验有限孔径、均匀移相、偏振旋向、衍射第一暗环、4f 倒像和多谱积分。
- [x] **材料与读图。** 在 `wave-views.js` 提供画笔、直线、矩形、撤销和守恒检查，按显示量选择色条与暗区掩膜。检查画布纵轴、非方形材料、涂满一种成分后继续绘制其他通道，以及光谱和区域积分的单位。
- [x] **工作站与验收。** 在 `wave.html`、`wave.css`、`wave.js` 连接光路编辑、计算任务、导入导出和手册。通过本地页面走一遍导入光路、绘图、选择观察面和探测器读数。核查不支持的下游、计算中修改参数、导入失败及窄屏操作。运行 `npm test` 并核对实际工作树。
- [x] **固定参考臂的检测。** 在可传播的单色相干场上生成四张移相强度图，重建相位与可见度，核对两个合束端口的能量。用同面透明台阶及独立调节的参考臂光程检验读数。
