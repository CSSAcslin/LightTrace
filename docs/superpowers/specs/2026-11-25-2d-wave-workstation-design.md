# 光迹二维波动工作站设计稿

本次更新的目标是让用户带着自己的光路完成一次二维成像实验。在进阶工作站调好照明与镜组，打开「二维波动工作站」，在任意可达的物面画一个物体，逐面观察它怎样改变光场，最后在有明确尺寸和像素的相机上读数。4f、衍射、偏振成像和移相干涉都使用这条实验流程。

## 从现有实验开始

- 进阶页新增「在二维工作站打开」。独立页面沿用光源、器件 ID、组名、次序、世界坐标、材料、曲率、厚度、孔径、光谱和偏振。两页共用材料色散和近轴基准。基础实验室继续提供薄透镜入门实验。
- 入口取点击当下的内存快照，沿用进阶页的 `guangji.surface-workbench` v1。短快照可随链接片段传入，超出可用长度时提供原格式 JSON 的导出与打开。直接双击本地 HTML 也应能凭 JSON 完成全流程。二维实验单独保存源快照、二维物体、局部光路改动、探测器和采样设置。重新从进阶页打开会创建一份新实验，以保存原有绘图。
- 左侧用同一条光路列出光源、物体、透镜、相位器件与相机。可插入多个物体，移动元件或相机，选择器件前表面或后表面的观察截面。截面只是取样。继承的探测屏接收有效面内的入射功率，后面的器件只收到仍能继续传播的场。
- 以原光路的 `x` 为纵向，横截面为 `(y,z)`。正向观察图统一向右为 `+y`、向上为 `+z`。首版轴对称镜片与圆孔绕光轴展开，旧光源和器件保留原有的 `y` 坐标，新增的横向中心坐标 `z` 默认为零。横截面两个刻度按相同比例显示。选中元件时标明坐标、物理尺寸、前后介质与采用的模型。
- 导入回执逐项给出「已映射」「近轴近似」或「需要补充参数／当前不支持」。未能解释的器件保留原始参数，阻止其影响范围内的下游结果。可在二维副本显式选择简化模型，结果图与导出会记录该选择。上游截面仍可查看。

## 二维物体与相位控制

物体具有物理宽高、位置和独立的绘图网格。可用画笔、直线、矩形、擦除、撤销及预设，绘制不对称字母、孔、双缝、透明相位台阶等。编辑时并排看当前材料通道和出射场。仿真网格加密、移动相机或改变画布缩放时，物体尺寸和笔迹位置保持一致。

| 可编辑量 | 作用 |
| --- | --- |
| 透射介质份额 T、镜面反射 R、散射 S | 按功率逐像素分配，吸收 A = 1 − T − R − S。画笔只改当前通道，最大笔值受该像素其他份额限制。材料区擦空后全部吸收，物体边界外为空气。透明相位板预设在材料区显式填入 T = 1。 |
| 光程差 OPD | 可用 nm 或参考波长下的 rad 编辑。透过相位板的复振幅乘以 exp(i 2π OPD / λ)。无界面损耗的振幅透射率为 √T。材料色散已知时按该波长的折射率和厚度计算 OPD。 |
| 相位控制元件 | 首批有可调均匀移相片、可画空间分布的理想相位板。后续加入可设像素间距与相位行程的空间光调制器、具有空间变化快轴和延迟的波片。元件可放在物面、傅里叶面或其他允许的平面。 |

旧物体的 33 格图案按原 `y` 区间逐格沿 `z` 拉伸，默认实体宽高均取原口径，图上标出这一假设。老格式的灰度乘材质比例按进阶引擎已有规则展开。折射属于进入透明介质后的传播过程。导入有厚度与折射率的试片时，透射份额还需按适用的界面模型计算 Fresnel 反射，记录采用的界面数和有效透过率。简化为理想相位板须明确选择。

混合物体可先计算「直透成像」。每个截面记下已传播、已吸收、已截获以及尚待计算的反射和散射功率。散射设置保留前向米氏、HG 或入射侧漫反射的区别。散射角分布本身不足以决定每个像素的相干相位。包含这些分量的总像须等相应分支模型可用后给出。

首版对近法向、平行表面、透明的有厚度试片给出单次直透结果。两面功率透过率分别为 τ₁、τ₂ 时，直透功率份额为 T τ₁ τ₂。第一面反射 T(1 − τ₁)，第二面返回材料内的 T τ₁(1 − τ₂) 单独登记，保留它们可能产生后续出射的含义。试片相位按相对同厚环境介质的光程差计算。有楔角、显著内部往返干涉或要求反射侧成像时，导入回执指出所需模型。

## 从光源到相机的计算

1. **定义照明。** 每个波长、空间相干模式保存一对横向复振幅 (Eᵧ, E𝓏) 及非负权重。继承的平行束默认展开为同直径的圆形平顶照明，点源按原发散半角设定角域，多视场的三个物点默认彼此独立。光源面板显示这些二维展开假设。旧实验中代表采样密度的光线数不参与设定波前。部分偏振可由同一空间照明下的两个独立偏振本征态表示。带宽与空间相干性分别控制。
2. **逐面传播。** 在均匀介质中用带限角谱法传播两个横向分量。对同轴近轴镜组，逐波长复用现有计算得到的 EFL、前后主平面与焦面位置，使用解析处理透镜二次相位的缩放衍射传播。有限孔径和空间掩模在各自所在面施加。傅里叶面按传播矩阵判定，并标明适用波长。物面、频谱面、像面都可以直接观察。[带限角谱法原论文](https://doi.org/10.1364/OE.17.019662) · [POPPY 波动传播与探测面采样](https://poppy-optics.readthedocs.io/en/latest/fresnel.html)
3. **器件更新复场。** 理想相位板修改相位，偏振片和波片作用于两个复振幅，沿用已有快轴与旋向约定。有限外径光阑仅遮挡实体环带。近轴厚透镜保留一阶焦距和色散，报告球差等高阶效应的覆盖情况。后续可由真实曲面及材料计算参考球面上的光程差，再做瞳面传播。偏心、倾斜、反射折转和衍射级次需要相应的坐标和能量模型。
4. **合成可观测量。** 同一波长同一相干模式中的路径先叠加复振幅。独立模式与独立波长采用加权强度和 Stokes 量求和。各波长先映射到同一物理探测坐标，再对矩形像素面积积分。离散谱线使用各线总权重，连续谱使用谱密度与波长积分权重。默认理想相机响应平坦，归一化入射总功率为 1。相机的截获功率、每像素功率和单位面积强度分别标注。
5. **干涉检测。** 提供可校准的同源参考光支路、参考相移和合束端口。首个测量模型使用相同投影偏振的单色相干照明。在参考臂依次施加 0、π/2、π、3π/2，由相机产生四张原始强度图。令 Iδ = |O + R exp(iδ)|²，其中 O、R 含分束和合束系数。用 atan2(Iπ/2 − I3π/2, I0 − Iπ) 恢复相对于参考光的包裹相位，显示条纹可见度和有效像素。重建只读取测量帧，理论复场用于独立核验。[Wyant 移相干涉讲义](https://wp.optics.arizona.edu/jcwyant/wp-content/uploads/sites/13/2016/08/phaseshiftinginterferometry.pdf)

**有限镜片的旁路。** 首版主平面模型计算通过镜片的那部分光。若实体外有照明，光也可能从空气绕行，随后与过镜光干涉。计算时估计外缘以外的入射功率份额并显示数值。超过数值噪声时，用户可先加实体光阑，或显式选择查看「仅过镜分量」，在账本中列出旁路份额，暂停整幅总像的定量读数。对重合的薄元件按列表顺序作用，光源、紧贴的物体和出口截面可以位于同一坐标。

**跨平面的相位零点。** 对每个波长和相干模式约定光源的发射相位为零，统一使用 exp(−iωt)。内核保留参考轴上光程、分离出的二次相位与传播算子的常相位，含厚镜内的轴向光程。读取复场或合束时还原到同一参考。图上可扣除用户明确指定的参考平面波或已保存的空场，并显示选用的参考。移动观察面后继续沿用该参考。首个干涉模块采用固定的理想 50∶50 分束与合束，在选定观察面注入已校准的同源参考波，提供参考光程与相移控制，并对两个输出端口记账。任意布置双臂元件属于第三阶段。

### 采样与本地计算

内置 4f 中继在 546.074 nm 的口径为 30 mm，单镜有效焦距约 63.66 mm。若直接在瞳面网格乘理想透镜的二次相位，边缘采样间距需约 λf/D ≈ 1.16 µm 或更小，覆盖口径约需每边 2.6 万点。用一张 512 × 512 网格同时表示整孔和焦斑，会产生混叠。焦面第一暗环半径约为 1.41 µm，这个数值对应**均匀照满圆孔的理想近轴基准**。继承预设中点源的发散角所照亮的有效孔径也要计入。

每个面独立记录视场、像素间距、有效束径及通带。使用解析去除二次相位、瞳面到焦面的傅里叶变换或缩放传播，在相机网格上按需取区域。加密网格与扩大计算窗口分别检查收敛，报告边界回卷、欠采样和未覆盖的视场。计算预算不足时，给出可行的局部视场或预览，并显示失效的定量读数。物理截光、画面裁切与数值截断分别记账。

首选离线浏览器引擎，在后台逐波长、逐模式运算，结果随配置版本更新，拖动时可取消过期任务。缓存按面失效，允许按需重算某一波长。先以 256² 交互预览、512² 定量模式为性能测试起点，精度由采样与收敛决定。记录典型机器的耗时、峰值内存与采样误差后，再决定是否加入 WebAssembly、GPU 或可选的本地计算服务。保留纯本地打开、保存和演示的路径。

## 结果怎样读

中央放物面与选定观察面的并排视图。可切换波长、照明模式、偏振投影和显示量。点击一个像素时，十字光标和下方读数联动。拖出一个区域可读出积分功率和区域光谱，画一条线可看指定波长的强度或有效相位剖面。图像导出带比例尺、单位、色条、波长、归一化方式和相位参考，可同时导出当前图层或剖面的原始读数和坐标。局部放大与对比度拉伸只影响显示。

| 图层 | 科学绘图与读数约定 |
| --- | --- |
| 强度与模拟相机图 | 强度使用顺序色图，支持线性和对数色标，在同单位图之间可以锁定共同色限。宽谱提供积分强度、逐波长切片和选区光谱。合成可见色预览单独标注映射规则。 |
| 相位与波前 | 对选定波长、相干模式和偏振投影，显示相对明示参考的相位。默认包裹至 [−π, π)，使用首尾相接的循环色图。暗点和参考无效处加掩膜。宽谱积分或独立模式混合时可查看强度、偏振或逐模式相位。 |
| 偏振 | 并列显示 S₀、S₁/S₀、S₂/S₀、S₃/S₀ 与偏振度。后三个有符号分量用零居中的发散色图，范围固定为 [−1, 1]。偏振度范围为 [0, 1]。可在强度图上稀疏叠加偏振部分的椭圆和旋向，标出观察方向。零强度处屏蔽归一化量，近零偏振度处隐藏椭圆。 |
| 相位测量 | 将模拟的光场相位、四张原始干涉图、重建相位与圆周相位误差分开显示，读数注明参考光与检偏轴。用户可以用透明试片观察到同面强度几乎均匀而相位出现台阶。 |

色图按物理量选择，可以从强度颜色的明暗顺序和相位 ±π 的连续性直接读图。偏振椭圆与 Stokes 分图互相补充，沿用进阶工作站 exp(−iωt) 下 S₃ = 2 Im(Eᵧ* E𝓏) 的符号。[Matplotlib 科学色图指南](https://matplotlib.org/stable/tutorials/colors/colormaps.html) · [空间分辨 Stokes 与偏振椭圆的实验图例](https://pmc.ncbi.nlm.nih.gov/articles/PMC7695742/)

## 交付顺序和验收实验

| 里程碑 | 可操作的实验 | 通过条件 |
| --- | --- | --- |
| 一 · 从光源到二维相机 | 带入同轴进阶实验，绘制二维透射与光程差，编辑相位片、光阑和理想偏振元件，在物面、傅里叶面与像面切换强度、偏振、光谱和有效相位 | 从旧 4f 配置开始，选平行照明并在第一镜前焦面放不对称图形，像面两轴倒转，放大率符合 −f₂/f₁。扫动相机出现离焦，再移回可恢复图像。均匀圆瞳的单色焦斑第一暗环半径误差目标 ≤ 2%，直通场的积分功率相对误差目标 ≤ 1%，均以足够采样的配置验收。 |
| 二 · 相位控制与检测 | 均匀照明下绘制 T = 1 的 π/2 台阶，在物体出口与同源参考合束，查看四帧、可见度和重建图。再在 4f 公共焦面编辑相位掩模，比较同一物体的像 | 无噪声且充分采样时，透明台阶两侧的出射强度相等，在双方有信号的台阶内部恢复的相位差距 π/2 小于 0.03 rad。两个独立模式相加强度时无干涉项。理想偏振片满足马吕斯定律，45° 线偏振经快轴 0° 的正四分之一波片得到 S₃/S₀ ≈ +1。 |
| 三 · 扩展既有器件 | 逐类接入曲面像差、折叠光路、带效率的光栅、多端口分合束与散射，再比较同一实验的几何截距与二维衍射像 | 为每类新增器件提供可以独立计算的基准。反射后验证局部坐标和旋向，光栅验证各级位置与能量，米氏散射验证前向峰与归一化。对未给出粒子位置和相干微结构的数据，散射成像输出统计强度与适用的偏振量。 |

首个交付就应打通保存与重开实验、二维绘画、照明、传播和探测。实验手册同步增加「从进阶 4f 到二维像」和「这张图代表什么」两个入口，随后增补相位测量与复杂器件实验。内置算例共用与自定义实验相同的引擎和编辑器。

此外，用同一个双缝物体在理想固定焦距的傅里叶面上比较两条谱线。条纹周期之比应等于波长之比，双线积分图应等于在同一相机网格上两张独立单色图的加权和。再将均匀相位片置于干涉仪样品臂，整体增加 π/2，四帧应相应移位，重建的共同有效区域应整体平移 π/2。两项都检验用户读出的分布和底层传播是否一致。
